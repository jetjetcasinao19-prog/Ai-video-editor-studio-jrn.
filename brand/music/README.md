# Brand music

Put songs here that you are **allowed** to use in posted videos (MP3, M4A,
WAV, OGG). The "edit this" workflow uses the first file (by name) when you
ask for music, at the volume in `brand/brand.json` (`music.volume`), lowered
automatically while you talk.

Safe sources (check each track's licence before use):
- YouTube Audio Library (studio.youtube.com → Audio library): free for YouTube
- Pixabay Music (pixabay.com/music): free licence, check attribution notes
- Music you bought a licence for, or made yourself

TikTok and Instagram also offer their own licensed sounds inside the apps:
those must be added in the app when posting, not here.

GitHub refuses files over 100 MB; songs are usually 3–10 MB, which is fine.
