- **Hook (first line of the video):** "Nobody picked this option, and that's exactly why it worked."
- **Summary:** The Economist once offered three subscriptions: web only $59, print only
  $125, and print and web, also $125. Who would pick print only? Nobody. Behavioral
  economist Dan Ariely tested the offer on 100 MIT students: 0 chose print only, 84 chose
  the $125 combo, 16 chose web only. When he removed the useless print-only option, only
  32 chose the combo and 68 took the cheap web option. The print-only option was a decoy:
  it made the combo look like a free upgrade. Next time you see three prices, ask which
  one is there just to push you.

- **Fact check:**
  - Source: Dan Ariely, *Predictably Irrational* (2008), chapter 1, "The Truth about
    Relativity". It describes The Economist's web subscription ad and Ariely's class
    demonstration with 100 MIT Sloan students: 16 web only, 0 print only, 84 print + web.
    With print-only removed: 68 web only, 32 print + web.
  - This is a classroom demonstration reported in a popular book, not a peer-reviewed
    paper. Say so if asked. Do not call it a "study proves".
  - The decoy effect (also called asymmetric dominance) was described by Huber, Payne &
    Puto (1982), "Adding asymmetrically dominated alternatives", *Journal of Consumer
    Research* 9. It is well studied, but its size varies by situation, so say "can" or
    "tends to", never "always".
  - The popcorn prices (S $4.00 / M $6.50 / L $7.00) are made up for illustration. They
    are not from the study. Never present them as real prices.
  - The "THE ECONOMIST · SUBSCRIBE" bar is a plain text bar with no logo. The wooden decoy
    duck, cobwebs and tumbleweed are illustrations, not documented details.
  - Optional note for replies, only if asked: some of Ariely's other research has been
    questioned (a 2012 paper was retracted over data problems). This example is not part
    of that, but don't oversell it, and don't claim it has been independently replicated
    in this exact form.
  - Keep it explain-not-manipulate: the tip is to spot the decoy when you see three
