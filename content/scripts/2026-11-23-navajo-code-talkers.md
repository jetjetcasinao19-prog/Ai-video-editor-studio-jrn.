## Voice-over script (read aloud)
In World War Two, one code was never broken…
and it was built by 29 Navajo Marines.

1942. Philip Johnston, a missionary's son who grew up speaking Navajo,
has an idea: use the Navajo language as a secret code.
The Marines say yes.
They recruit 29 young Navajo men.
They build a code inside their own language.
Everyday Navajo words become military terms.

In battles across the Pacific, they send message after message.
The enemy never breaks the code.
But when they come home, they can't tell anyone.
The code stays secret until 1968.

Their language… became the code that helped win a war.

Every legend has a beginning.
