# Research — The decoy effect

Niche: psychology / mind tricks. Format: under-60 s YouTube Short.

## The example (The Economist subscription ad)
- Source: Dan Ariely, *Predictably Irrational* (2008), chapter 1,
  "The Truth about Relativity".
- A real Economist web ad offered:
  - Economist.com (web) only: $59
  - Print only: $125
  - Print + web: $125
- Ariely gave the offer to 100 MIT Sloan students:
  - With all three options: web 16, print only 0, print + web 84.
  - With the print-only option removed: web 68, print + web 32.

## Caution
- This is a classroom demonstration reported in a popular book, not a
  peer-reviewed paper. Some of Ariely's other work (not this example) has
  faced data-integrity concerns. The script says "a behavioral economist
  tested it" and keeps to the numbers he reported.
- The effect itself is established in research: Huber, J., Payne, J. W., &
  Puto, C. (1982). "Adding asymmetrically dominated alternatives: Violations
  of regularity and the similarity hypothesis." *Journal of Consumer
  Research*, 9(1), 90–98. https://doi.org/10.1086/208899
  (Also called the "attraction effect". Later studies show it is real but
  varies by situation.)

## Explanation (safe to say)
- A decoy is an option almost nobody wants. It is there to make another
  option look like a better deal by comparison.
